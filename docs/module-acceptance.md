# Per-module “Done when” acceptance tests

This is the acceptance checklist; a listed condition is not claimed complete unless the test/evidence exists.

| Module | Done when |
|---|---|
| M0 Foundation/DevOps | Clean Python 3.12 environment installs dependencies; lint/tests run; CDK synthesizes offline; config and outputs are documented. |
| M1 Identity/access | Cognito PKCE sign-in/team claims work; each Lambda has a least-privilege role; ProvisionerRole positive and negative IAM cases are live-tested. |
| M2 Data/ledger | Five exact-key tables are locally synthesized with Reservations team/creation and status/expiry GSIs, Budgets/Reservations PITR, and idempotency-only TTL. Moto tests cover budget and reservation state transitions, invariant preservation, duplicate/conflicting idempotency, insufficient and concurrent reservations, safe workflow-unknown release rejection, settlement retries/corrections/overruns, and indexed queries. A separate approved integration run verifies conditional transactions, contention, GSI behavior, TTL, and IAM against real DynamoDB. |
| M3 Pricing | Fixture/provider tests cover supported SKUs, product/dimension selection, Price List pagination, missing/conflicting prices, cache expiration, provenance, and upward integer-micro-USD rounding. A live Mumbai Price List snapshot is separately verified and labelled before any live-price claim. Estimates identify compute and gp3 storage separately and document exclusions. |
| M4 Admission | A verified identity from the auth adapter is required; team mismatch is denied; fixed 1.10 reserve is rounded up; team/period/idempotency are passed to the atomic M2 ledger; duplicate and conflicting key behavior, insufficient budget, concurrent admissions, and ambiguous outcome reconciliation pass unit/Moto tests. No workflow starts before durable confirmation. Live JWT/team authorization, DynamoDB transactions/contention, and route integration are verified separately and are not claimed by local tests. |
| M5 API | All nine routes are wired to Cognito-authorized API Gateway methods and distinct least-privilege Lambda roles. Local handler tests cover response envelopes/statuses, developer/admin claims, team isolation, M4 idempotency/pending outcomes, M2 reads/writes, and read-only unsupported cancellation. CDK synthesis and live Cognito/API Gateway/IAM verification remain separately required before deployment. |
| M6 Orchestration | Standard workflow starts only after a durable hold; deterministic execution identity and unknown-start recovery are durable; restricted ProvisionerRole uses reservation/team STS tags; EC2 request has no public IP/key pair/ingress, uses approved SKU/gp3, ownership tags, encrypted delete-on-termination volume and IMDSv2; workflow waits/polls, records instance/volume IDs and activates; tag-scoped failure cleanup is idempotent; controlled pre-launch injection safely releases. Partial-resource or ambiguous failures remain held until cleanup and billing evidence establish safe accounting. Local fake tests and CDK synthesis pass; live execution/IAM/network verification remains required. M7 expiry scheduling and M8 settlement are not part of this milestone. |
| M7 Lifecycle | Expiry and sweeper terminate only verified tagged resources; replay, unrelated-instance, bypass alert, and cleanup tests pass. |
| M8 Billing | CUR 2.0 export schema is inspected; fixture reconciliation and delayed/versioned settlement tests pass; actual billing is queried before live verification. |
| M9 Calibration | Fixed, rolling, frozen split-conformal and adaptive policies pass bounds/dedup/order/lag tests; research artifacts reproducibly regenerate. |
| M10 Web | Hosted UI, authenticated API, all required screens and private S3/CloudFront/OAC are browser-verified after deployment. |
| M11 Observability | Dashboard, log retention, alarms, DLQs and SNS delivery are deployed and each alarm/email path is exercised. |
| M12 Test/demo/teardown | Local/integration/concurrency/failure suites, repeatable demo, tag-scoped dry-run teardown, and post-run EC2/EBS inventory are evidenced. |
